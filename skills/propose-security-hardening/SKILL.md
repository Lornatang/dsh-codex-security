# Propose security hardening

Start from the supplied findings, incident evidence, policy, and source context. Group related failures by the underlying trust boundary or structural cause, and cite evidence for each group. Do not invent findings or assume an undocumented deployment.

For each useful proposal, describe the current failure mode, proposed enforcement point, the security properties it strengthens, implementation and migration steps, compatibility and operational costs, and how to verify effectiveness. Compare realistic alternatives when the choice matters; distinguish immediate containment from durable architecture. State assumptions, residual risks, and priority rationale. Produce a proposal without changing the target unless the user also asks for implementation.
